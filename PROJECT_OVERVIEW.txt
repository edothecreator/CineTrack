================================================================================
  CINETRACK — PROJECT OVERVIEW
  Next.js 16 · React 19 · Tailwind v4 · Prisma 6 · PostgreSQL (Supabase)
================================================================================

THEME
-----
- Product name: "CineTrack" — premium cinematic identity system.
- Visual direction: dark-first (#0B0B0F), gold accent (#F5C542), purple accent
  (#A78BFA), glassmorphism surfaces, cinematic hero imagery, Framer Motion.
- Light/dark theming via CSS variables and next-themes (defaults to dark).
- Data source: TMDB API v3 — Bearer token, server-side only.
  All TMDB logic centralized in src/lib/server/tmdb.ts.


TECH STACK
----------
  Framework:    Next.js 16.2.1 (App Router)
  UI:           React 19, Tailwind CSS v4, Lucide React, Framer Motion
  Database:     PostgreSQL via Prisma ORM (Supabase)
  Auth:         JWT + HTTP-only cookies, bcryptjs
  Deployment:   Vercel + Supabase
  CI/CD:        GitLab CI (validate → build → test → security → docker → deploy)


ENVIRONMENT VARIABLES
---------------------
  DATABASE_URL            Supabase pooled (port 6543, pgbouncer)
  DIRECT_URL              Supabase direct (port 5432, migrations)
  AUTH_SECRET             JWT signing secret
  TMDB_API_READ_TOKEN     TMDB v4 Read Access Token (Bearer)

================================================================================
  FUNCTIONALITIES
================================================================================

HOME (/)
--------
- Hero carousel: auto-rotating spotlight, parallax mouse effect, backdrop images.
- Trending / Popular rail toggle with animated tab indicator.
- Vibe genre filter chips (Action, Sci-Fi, Comedy, Crime, Animation).
- Mobile horizontal scroll + desktop grid.
- Data: GET /api/home-discovery (TMDB trending + popular).

DISCOVER (/search)
------------------
- Debounced TMDB multi-search (movies + TV).
- Grid / list view toggle.
- Infinite scroll on results (Intersection Observer).
- Empty query shows trending defaults.

TITLE DETAIL (/movie/[id])
--------------------------
- IDs: movie-{tmdbId} / tv-{tmdbId}.
- Full TMDB data: poster, backdrop, synopsis, tagline, rating + vote count,
  runtime, genres, status, budget, box office, original language, keywords,
  production countries, spoken languages, studios, networks, content rating.
- Filmmakers section: created by, directors, writers (linked to person pages).
- Cast grid with photos, linked to person pages.
- Trailers (YouTube links).
- Watch providers (streaming badges, US region).
- Episode tracker for TV series.
- Community stats: watched count, in-list count, avg user rating, recent scenes.
- Action buttons: Save to list, Mark as watched (with rating modal),
  Drop a Scene (pre-filled composer), Add to Collection.
- OpenGraph meta tags for social sharing.

EPISODE TRACKER (SeriesEpisodeTracker)
--------------------------------------
- Season tabs with per-season watched/total counter.
- Episode stills from TMDB, rating, runtime, air date per row.
- Spoiler shield per episode (auto-revealed when marked watched).
- Expandable overview with More/Less toggle.
- "Mark all Season X as watched" quick action.
- Progress bar for overall series completion.

WATCHLIST / ARCHIVE (/my-list, /watchlist)
------------------------------------------
- Titles queued to watch. Search within list.
- Release radar section for upcoming titles.
- Surprise Roulette random picker.
- Guest mode: localStorage, merged on login.

WATCHED HISTORY (/watched, /history)
-------------------------------------
- Titles marked as done. Search within history.
- Per-card user rating display (click to remove, "+ Rate" to quick-rate).
- Remove from history button.

USER RATINGS
------------
- Personal 1–10 star rating stored on WatchedTitle.userRating.
- Rating modal when marking as watched (optional, can skip).
- Re-rate from detail page sidebar or history grid.
- Feeds into community avg rating and Taste Match calculation.

COLLECTIONS (/collections)
---------------------------
- Named user lists (max 20 lists, max 500 items each).
- Create / rename / delete collections.
- Public or private toggle per collection.
- Add to Collection button on every title detail page.
- Collection detail page with poster grid, remove items.

SOCIAL SYSTEM
-------------
Follow / Unfollow
  - POST /api/users/[username]/follow
  - Mutual follow detection, NEW_FOLLOWER + FOLLOW_BACK notifications.

Stream (/feed) — 3 tabs:
  Following  — scenes from followed users (auth required)
  Trending   — most signalled scenes in last 7 days
  Global     — all scenes newest first
  Infinite scroll on all tabs.

Scenes (Posts)
  - Types: MEDIA (linked to TMDB title), TEXT (pure take), IMAGE (with caption).
  - Fields: text, rating, isSpoiler, takeType (hot/fact/question).
  - Drop a Scene from the Stream page composer OR directly from any title page.
  - @mention support: parses @username, sends SCENE_MENTION notification,
    renders as clickable links in scene text.

Signals (Reactions)
  - 5 types: love ❤️, fire 🔥, wow 😮, sad 😢, haha 😂.
  - One per user per scene, toggleable, optimistic UI.
  - Triggers SCENE_REACTION notification to scene author.

Resonance (Comments)
  - Threaded 1 level (replies to top-level comments).
  - Triggers SCENE_COMMENT notification to scene author.

Notifications
  - Bell in header with unread count badge, polls every 60s.
  - Types: NEW_FOLLOWER, FOLLOW_BACK, FRIEND_WATCHED, FRIEND_ADDED_LIST,
           SCENE_REACTION, SCENE_COMMENT, SCENE_MENTION.
  - Mark all read on open.

User Search
  - GET /api/users/search?q= — by username or display name.
  - UserSearch component in desktop header.

Public Profiles (/user/[username])
  - Avatar, display name, bio, follower/following counts.
  - Taste Match % badge (inline + card with arc progress).
  - Recently watched grid.
  - Follow button.
  - Privacy: private profiles locked to non-followers.
  - OpenGraph meta tags.

Followers / Following lists (/user/[username]/followers|following)

Own Profile / Archive (/profile)
  - Edit bio, avatar, display name, banner, public/private toggle.
  - Tabs: Overview (stats, binge clock, recent activity, quick links),
          Stats & DNA (genre fingerprint, completion rate, streak),
          Settings (avatar, bio, data export).
  - Data export: JSON or CSV download of watched history + watchlist + collections.

TASTE MATCH
-----------
- Computed between viewer and any other user.
- Algorithm: 40% watch overlap (Jaccard) + 40% rating correlation (Pearson)
  + 20% genre affinity (cosine similarity). Returns 0–100%.
- API: GET /api/users/[username]/taste-match (auth required, cached 5 min).
- Displayed as inline badge + animated arc card on public profiles.

PERSON PAGES (/person/[id])
----------------------------
- TMDB person detail: photo, name, credits list.
- Overlap badge: "You've seen X% of catalogued roles".

HALL OF FAME (/pantheon)
------------------------
- Top rated movies + TV from TMDB, paginated (20/page, up to rank 100).
- Top 3 get medal emojis + gold/silver/bronze treatment.
- Client-side page cache.

COMMUNITY STATS (TitleCommunityStats)
--------------------------------------
- Per-title: watched count, in-list count, avg user rating, recent scenes (30d).
- Shown in left sidebar of every title detail page.
- API: GET /api/title-stats?id={tmdbId} (cached 60s).

STATS
-----
- Binge Clock: POST /api/binge-stats — aggregates TMDB runtimes.
- Watching DNA: POST /api/watching-dna — top genres, completion rate,
  total watch minutes, longest binge streak.

AUTHENTICATION
--------------
- JWT in HTTP-only cookie (AUTH_SECRET).
- Register / Login / Logout / Session / Bootstrap.
- Guest mode: full app usable without account (localStorage).
- Guest merge on login: POST /api/me/merge-guest.

INFRASTRUCTURE (Session 5)
--------------------------
- OpenGraph + Twitter Card meta tags on title pages and user profiles.
- Data export: GET /api/me/export?format=json|csv.
- Infinite scroll: Intersection Observer hook (src/hooks/useInfiniteScroll.ts)
  used on Stream feed and Discover search results.
- Rate limiting: not yet implemented (planned: Upstash Redis).
